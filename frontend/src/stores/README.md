# 跨页面状态

`oddsSelection.ts` 用 Vue `ref` 在比赛页面与聊天之间共享所选比赛标识、平台标识和展示标签。不会在浏览器存储报价；发送时由后端读取最新保存的快照。取消选场或新对话清除选择，刷新网站后也会清空。

`startupGate.ts` 用浏览器的 `sessionStorage`（只在当前标签页有效的临时存储）记录是否已经从启动页进入系统，并在内存里记住用户原本要打开的地址。不保存任何业务数据。

`App.vue` 使用 Vue 自带的 `KeepAlive` 保留 `ChatView`，切换页面后聊天历史与未发送输入仍在；不保留比赛页的计时器。当前无需引入 Pinia（Vue 常用的状态管理工具）。局部的后端连接状态放在 `composables/useBackendHealth.ts`。聊天与任务需要刷新后恢复时，必须以服务端持久记录为准，不能仅靠前端内存。
