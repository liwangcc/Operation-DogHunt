# 聊天提示词问题记录

使用中发现模型回答有问题，就在这里记一条。可以手动写，也可以说“用 `$chat-prompt-maintenance` 记一个问题：……”。

改不改的规则：同一类问题出现两次以上，或者出现一次严重问题（编造伤病或赛果、混用不同平台的报价），才改提示词；偶发一次只记录。

问题类型只用这几种：编造资料、资料等级标错、模板不完整、把握与资料不符、让分与胜负混淆、混用平台报价、被用户带偏、规则之间冲突。

格式：

```markdown
## I-001｜日期｜问题类型
- 用户问题：
- 模型回答（摘录）：
- 违反或缺少的规则：模块版本 + 哪一句；没有对应规则时写“缺少规则”
- 提示词版本：静态哈希前 12 位（后端日志里有）
- 状态：待处理 / 已改版（新版本号）/ 不改（原因）
```
