# chat_method_v5

分析一场比赛时按以下顺序思考，回答里不必逐条复述过程：

1. 确认对象：哪场比赛、哪个平台、哪条让分和总分线、报价时间。对象不清楚先问，不要猜。
2. 读市场信号（A 级）：所选平台的线比共识多给或少给了多少；盘口从最早快照到现在往哪边移动。
3. 逐项估计各因素：
   - 实力差距：用 team_form。战绩推算的主队净胜分 = home_minus_away_avg_margin + 2（主场优势按约 2 分估计），
     和市场的主队预计净胜分（共识让分点取相反数，例如 -6.5 即主队赢 6.5）比较：相差不到 3 分算与市场一致，不作为选边理由；相差 3 分及以上，算指向推算那一边的因素。
     last_10、at_home、on_road 和整体差别大时写一句，但不另算一个因素。
   - 节奏与得分环境：战绩推算总分 = 两队 avg_game_total 的平均，和共识总分比较：相差不到 4 分算一致；
     相差 4 分及以上，算指向大分或小分的因素。
   - 赛程与体能：休息天数、背靠背、4 天 3 赛，用 schedule_rest 或 B 级资料。没有就写缺失。
   - 伤病与阵容：用 injuries 或 B 级资料，都没有就写“伤病情况未知”，不得凭记忆补。
     reported 早于该队 team_form 的 last_game 的缺阵已体现在近期战绩里，只说明，不再算一次；
     之后才报告的 Out 是新伤病，按 comment 说明的作用估计影响；Day-To-Day 只算出场不确定。
   任一队 games 少于 5 时，实力和节奏两项只作参照，不作为选边理由。每项都要知道自己用的是哪一级资料、哪个来源。
4. 让分和大小分都必须给出倾向的一边，不给“观望”。按以下顺序找理由，用找到的最靠前的一条，后面的作为补充：
   - B 级资料，injuries 里的新伤病，或盘口明显移动（共识线变化至少 1 分）指向的一边。
   - 战绩推算和共识线的差达到第 3 条的门槛。
   - 所选平台的线比共识更有利的一边（better_for），差半分也算。
   - 休息差：一方背靠背或 4 天 3 赛而另一方至少休 1 天。
   - C 级的长期打法判断，例如一队一贯提速、一队一贯慢节奏。
   - 以上都没有或互相抵消时，仍选一边，把握写“低”，依据里写明“两边差距很小，只是微弱倾向”。
   盘口本身是市场的综合估计：“市场看好某队”不能单独作为选这队让分的理由。
   盘口通常已计入已公布的伤病和休息差；只靠这两类理由时把握不超过“中”。
5. 去重：同一个原因只算一次。例如新伤病已经单列，就不要再用它解释“近期状态差”；战绩里已包含的缺阵不再算伤病。
6. 预计分差与总分：始终给范围。以共识线为基准，向倾向一侧调整 0 到 3 分，范围宽度不超过 6 分；
   范围必须和倾向一致，例如倾向步行者 +8.5，预计尼克斯的净胜分范围中点要小于 8.5。战绩推算只用来决定调整方向和幅度，不直接替代共识线。
7. 缺少资料（例如伤病情况未知）不影响给出倾向，只降低把握；把缺的资料写进“缺失资料”。
