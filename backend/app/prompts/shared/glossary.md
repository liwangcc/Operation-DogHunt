# 术语与符号约定

- **主队 home / 客队 away**：以 `<game_data>` 中的 `home` 和 `away` 为准。
- **分差 margin**：主队得分减客队得分。正数表示主队占优，负数表示客队占优。
- **总分 total**：两队得分之和，包含加时。
- **让分方向 spread_lean**：本因素利好哪一方。`home` 利好主队，`away` 利好客队，`neutral` 表示本因素对分差没有明显影响，`insufficient` 表示数据不足。
- **总分方向 total_lean**：本因素让总分偏高（`high`）还是偏低（`low`），`neutral` 表示没有明显影响，`insufficient` 表示数据不足。这是因素本身的方向，不是买大还是买小。
- **missing**：你认为判断所需、但输入里缺少的数据。输入的 `missing` 已列出的缺失项要照抄进来。

## 分数：基准与修正

汇总时会把各块的分数相加，所以每个分数字段只有一种含义：

- **基准分数**：`margin_pts` 是完整的预计主队分差，`total_pts` 是完整的预计总分。只由负责给基准的块输出。
- **修正分数**：`margin_adj_pts` 是本因素让主队分差变化多少分，正数利好主队；`total_adj_pts` 是本因素让总分变化多少分，正数偏高。只写本因素带来的变化，不含基准。
- 汇总的预计分差 = `margin_pts` + 各块 `margin_adj_pts` 之和；预计总分同理。
- 分数都不看盘口，不是相对让分线或总分线的差。
- 本块输出哪些字段，以本块的 `output_schema` 为准。

## 把握 confidence

0 到 100 的整数，表示对方向判断的把握，不是赢盘概率，也不是胜率。按下面的刻度给：

- **0**：方向为 `neutral` 或 `insufficient`。
- **1–30 低**：依据少，或指标之间有矛盾；数据稍有变化，方向就可能反过来。
- **31–60 中**：主要指标同向，但差距不大，或样本偏少。
- **61–100 高**：多个互相独立的指标同向且差距明显，样本充足。
