# 后端模型极高思考强度

日期：2026-11-13（Asia/Shanghai）
状态：✅配置与离线验证完成；中转实际支持情况未验证。

## 目标与选择

用户希望项目后端模型使用“极高”思考强度，不再依赖中转默认值。原 `request_model` 没有发送思考强度。新增 `DOGHUNT_MODEL_REASONING_EFFORT`，默认与本机 `backend/.env` 都设为 `xhigh`，每次通过 Responses 请求体的 `reasoning.effort` 传递。使用原有后端配置方式，避免把配置只写进提示词而没有真正进入接口参数。

聊天与功能块默认共用 `request_model`，因此都读取该配置；功能块仍没有网站调用入口。前端没有新增调节控件。其他档位可在后端 `.env` 设置，修改后需重启；本轮已有开发服务通过源码变动自动重载，健康检查正常。

## 修改范围

`backend/app/core/config.py`、`backend/app/integrations/llm.py`、`backend/.env.example`、本机不入 Git 的 `backend/.env`、`backend/tests/test_chat.py`、`README.md`；同步 `docs/codebase/backend.md`、`CODEBASE.md` 与交接索引。没有修改提示词。

## 限制与踩坑

- 初次按文件名定位的 `services/model.py` 不存在，实际出站请求位于 `integrations/llm.py`。
- 文档检索工具没有返回有效来源；直接读取官方页面也没有及时完成，已停止该读取。随后成功读取 OpenAI 官方 `openai-python` 仓库的 `src/openai/types/shared_params/reasoning.py`，确认 `reasoning.effort` 包含 `xhigh`，且注明并非每个模型支持所有档位。该证据不代表当前中转模型兼容。过程中给出的无效文档引用已向用户更正。
- 模型或中转不支持 `xhigh` 时会报错，不会自动降档；HTTP 400 提示加入检查思考强度。
- 保留 120 秒超时与 4096 tokens 生成预算，极高强度可能让等待、费用与截断情况增加；未擅自提高预算，是否需要调整应根据真实使用结果决定。
