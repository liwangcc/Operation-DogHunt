# 预测记录 UI 框架

日期：2026-11-12（Asia/Shanghai）
状态：✅本轮 UI 范围完成；真实预测、赛果、数据库和记录保存尚未实现。

## 用户决定与交付边界

用户先确认首版用于自己的选场复盘，随后要求先搭显示哪些记录和内容的 UI，数据预测结果以后再做。多人开发的数据库位置、共享范围和账号权限尚未确定，本轮不选型、不接后端、不自动分析比赛。

## 界面与设计理由

沿用现有深绿侧栏和浅色卡片，避免换页风格割裂。上方展示选场记录、待结算、待复盘和已复盘数量，突出个人复盘流程，不占用效果统计页的收益分析职责。每条记录对应一个玩法，让分与大小分分别展示。概览固定统计全部示例；筛选只作用于下面的列表。

玩法、比赛日期、结算状态、球队或编号搜索、仅看待复盘均可操作，支持组合筛选和重置。列表按比赛时间降序；桌面右侧显示选中详情，较窄窗口和手机把详情排到列表下面。详情预留当时选择、平台、赔率、记录时间、理由、不确定因素、赛后比分和复盘笔记。

初次打开显示 6 条明确标注为虚构的示例，以便直观看布局，并能切换查看空白状态；搜索无结果有单独提示。笔记可以临时试填，清楚提示不会保存，不显示虚假的保存成功，不改变统计状态。切换示例/空白、刷新或离页后笔记恢复。去选比赛只跳转既有比赛页，不主动刷新盘口或发送模型请求。
