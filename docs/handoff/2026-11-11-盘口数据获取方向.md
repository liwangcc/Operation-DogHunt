## 获取方法与取舍

手工从固定来源查看并录入，适合少量比赛先验证信息是否够用，但每天需要人工更新。通过数据服务的 API 获取，适合网站自动同步；API 可理解为程序向数据商取数据的通道。第三种方式是网页抓取，需额外处理网页变化和来源使用规则，目前没有确定采用。

项目此前核对过 The Odds API 文档，其 `spreads` 市场对应让分，`totals` 对应大小分；可作为试接候选。用户本轮选择先讲获取方法，因此没有继续核实当前价格、免费额度、目标平台覆盖和访问可用性，也没有注册、购买或使用密钥实测。不能声称供应商已选定、免费方案一定够用或已经取得真实数据。

参考资料：https://the-odds-api.com/liveapi/guides/v4/#get-odds

建议最少保留比赛标识、开赛时间、主客队、让分对应球队及正负数值、总分线、报价平台、来源更新时间和采集时间。不同平台可能报不同盘口，比较和保存时必须带上来源。赔率与盘口数值不同；用户当前可以先看盘口，后续若统计模拟盈亏需一并保存赔率。
