# 三页切换深色方案与共享演示

日期：2026-11-13（Asia/Shanghai）
状态：✅完成本地实现与验证；未提交、未推送。

## 用户确认的范围

用户发现预测记录、效果统计、设置与其他内页视觉不一致，随后明确选择“界面、演示数据和交互都换成另一版”。本轮据此替换三个页面的入口实现，而非只调整颜色。

本地可达提交历史与不可达提交检查均未找到完整的另一版三个页面源码。仓库保留了另一版的记录模型、虚构数据、结算计算、详情抽屉和统计组件，因此复用这些现有模块，并参考前端代码地图中的另一版设计说明重新实现页面入口。不能将本轮描述为逐字恢复原始三页文件。

## 现在的行为与取舍

- 三页使用现有深色公共面板、按钮、表单和青色强调；AppShell 移除针对三页的浅色特殊背景。
- 记录与统计共同读取 `stores/records.ts` 的 `predictionRecords`，数据来自 `demo/records.ts`。赛果、盘口、球队均为醒目标记的虚构“沙盘联赛”。盈亏由 `domain/settlement.ts` 计算，汇总和曲线由 `domain/metrics.ts` 计算，避免列表与统计各自编造数字。
- `useRecordScope.ts` 与 `RecordFilters.vue` 提供共用筛选：时间、玩法、记录来源、判断来源、策略。默认最近 30 天、赛前记录、系统判断；日期按北京时间，全部时间含未来待开赛。来源不混算。跨页链接携带这些共同条件，记录专用的搜索和结算状态不传给统计。
- 记录支持结果筛选、球队/编号搜索、详情抽屉与 CSV 导出；CSV 与最终可见列表一致，保留十进制原始赔率并明确标记虚构数据。详情展示判断、盘口、依据、结算算式和只读笔记。
- 统计接入命中率圆环及区间、净盈亏、ROI、覆盖率、累计曲线、结算分布、周表现和策略版本对比。模拟金额沿用另一版的“每次 1 单位”，不代表实际资金。
- 设置改为运行状态、本机显示偏好和只读后台规则。赔率格式、默认报价平台、动态背景和演示开关即时生效并由既有 preferences 模块保存到本机 localStorage。状态检查仅 GET 本机后端；读取模型配置不代表模型在线，重读快照不触发供应商取数。
- 全局演示开关现在覆盖记录、统计、记忆及无真实数据的比赛页；记录/统计顶部演示按钮也与该开关联动。真实盘口仍优先使用。

用户选择整体切换，因此旧版填写复盘、归档、补充、整理清单和五分类“暂存预览”设置不再出现在当前入口。`features/reviews/`、`features/statistics/`、`data/recordPreview.ts` 文件保留，没有删除；当前复盘笔记只读。正式预测/复盘保存、赛果接入、真实统计及后台配置编辑仍未实现。

## 实际验证

使用正在运行的 5173 开发服务、独立 Chromium 浏览器上下文和模拟接口，没有操作用户浏览器的偏好。

- `npm --prefix frontend run build`：类型检查通过，`268 modules transformed`。
- 默认条件：95 条记录，模拟净盈亏 +6.34 单位；曲线终点与汇总值一致。
- 让分筛选：48 条记录，净盈亏 +2.93 单位；点击前往统计后玩法和数值保持一致，重置恢复默认值。
- 导出 CSV：48 条数据行，含 UTF-8 BOM 与“演示数据（虚构）”标记，条数与筛选后的列表一致。
- 五种结算情况断言：loss、push、win、pending、void 均通过。
- 详情抽屉 Tab 焦点保持在面板中，Escape 关闭；收益曲线可用方向键显示逐条读数。
- 设置切换香港盘显示 0.91，默认平台和背景可修改；刷新后赔率、平台与背景偏好保留。重新检查全部状态可完成。
- 关闭全局演示后，记录和统计均显示正式数据待接入的空状态，顶部演示标识消失；重新打开后恢复演示。
- 三页 1440px / 390px 六个布局检查：整页横向溢出均为 0，根样式 dark，无 light-page。记录宽表和周图允许在各自容器内滚动。
- 浏览器 pageerror 为 0，所有被拦截的 API 请求均为 GET；没有请求 `/chat` 或 `/odds/refresh`。
- 已查看桌面与手机截图；测试脚本与截图位于 `/tmp/doghunt-dark-pages-check.cjs`、`/tmp/doghunt-*.png`，属于临时验证产物，不应依赖长期存在。
