# 设置按钮框架

日期：2026-11-12（Asia/Shanghai）
状态：✅本轮界面框架完成；真实配置保存与应用后续开发。

## 目标与范围

用户准备开发设置位置，要求先搭大概的按钮框架。本轮替换 `/settings` 的占位说明，提供五类入口、表单和按钮交互；不确定数据库、账号范围或设置 API，不改后台配置与密钥，不发起模型调用或盘口更新。

## 界面与选择理由

沿用深绿侧栏、浅色卡片、克制的金色点缀，与项目已有页面保持一致。设置分类按用户要做的事情组织，便于以后逐项接功能：

- 基础偏好：语言预留、时区、赔率格式、舒适/紧凑按钮。
- 数据与盘口：现有供应商展示、参考平台、手动更新与过期提醒选项。
- AI 与调用：沿用后台模型、连接管理预留、等待上限、不自动重试、额度提醒开关。
- 分析与记录：关注玩法、确认记录、保留当时盘口与站内复盘提醒开关。
- 数据管理：跳转记录和记忆；导出、导入按钮禁用待接入。

设置按桌面左侧分类、右侧表单排列；950px 以下分类横排，700px 以下下拉框铺满一行。按钮和开关有明确选中状态，原生控件具备文字标签。

顶部标记“界面预览”，未实现的功能直接禁用并说明原因。暂存按钮命名为“暂存预览”，仅保留本页状态，避免让用户误以为真实配置已保存。没有把 API 密钥放进表单、浏览器存储或演示内容。平台、超时和提醒值为框架示例，不能视为最终业务规则。
