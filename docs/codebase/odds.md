## 负责什么

API 是程序访问外部服务的通道；此工具通过 The Odds API 获取已有报价的 NBA 赛前全场让分和大小分，保存当时的数据。快照像一张带时间的照片，只代表采集那一刻。

## 到哪里找实现

| 源码或配置 | 入口或关键符号 | 用途 |
| --- | --- | --- |

## 输入、输出和依赖

- 输入：`THE_ODDS_API_KEY`；请求 NBA、美国地区 `us`、`spreads,totals`，十进制赔率。
- 输出：`data/odds/<UTC时间>-<随机编号>/snapshot.json` 和 `odds.csv`；原始响应、整理记录、采集时间与额度信息分开保存。
- 依赖：原脚本使用 Python 3 标准库和外部 The Odds API；网站通过 [后端适配层](../../backend/app/integrations/odds.py) 复用脚本，经 [盘口服务](../../backend/app/services/odds/board.py) 和 [路由](../../backend/app/api/routes/odds.py) 提供给 [前端卡片](../../frontend/src/components/odds/MatchBoard.vue)。
- 使用入口与限制详见 [API 取数说明](../API取数使用说明.md)。

## 限制、未决事项与下一步

- 只返回已有报价的比赛；空列表不能证明全天无比赛，报价时间也不保证足够新。
- 用户已选择手动更新；无定时请求或自动重试。网页端 60 秒间隔防连点，进程内锁防并发，不限制独立脚本。
- 多家平台数据分别保留，卡片默认显示数据源首家，可切换；未选定唯一主参考平台。
- 比赛页已独立到 `/matches`；选场后通过比赛与平台标识进入聊天，后端读取同一快照并隔离平台。未选场聊天也会读取全部保存比赛；来源、采集时间和报价时间一并提供，不宣称实时数据。选场失效须重选或取消。
- 本次真实模型回答中，凯尔特人对猛龙 DraftKings 总分为 216.5，未误用 FanDuel 的 215.5；没有请求外部盘口或生成新快照。详见 [交接](../handoff/2026-11-11-独立比赛页与AI盘口联动.md)。
