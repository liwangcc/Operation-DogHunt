# NBA 盘口 API 最小取数

已为 The Odds API 准备单次取数脚本。只用 Python 3 标准库，无需安装第三方包。不会自动定时更新、重试或购买套餐。

网站首页也已接入同一取数能力：先显示本地已保存比赛与盘口，点击“更新盘口”才请求一次外部接口（通常 2 credits）；“重新读取”和日期、平台切换不消耗额度。网页刷新间隔至少 60 秒，失败保留旧快照，不自动重试。只覆盖已开盘比赛，尚未接完整赛程或实时比分。

## 使用

在项目根目录 `.env.local` 中填入邮件里的 Key 并保存：

```dotenv
THE_ODDS_API_KEY=在此处填写自己的Key
```

不要把真实 Key 发到聊天、放到网页前端或提交进版本管理。配置文件权限为仅当前用户可读写，`.gitignore` 已排除 `.env.local`。`.env.example` 是不含 Key 的示例。脚本也支持读取同名环境变量，环境变量优先。

在项目目录运行：

```sh
python3 scripts/fetch_nba_odds.py
```

每次只发送一个请求到 `https://api.the-odds-api.com/v4/sports/basketball_nba/odds/`，取美国地区 `us` 的 `spreads`（让分）和 `totals`（全场大小分）。一个请求可返回多场比赛和多家平台的报价，不是每场扣一次额度。正常两个市场、一个地区通常扣 2 credits，以返回的实际额度为准。

## 结果

每次新建 `data/odds/时间-随机编号/`，不会覆盖过去的采集结果：

- `snapshot.json`：程序可以直接读的结构化数据文件，保留完整接口响应、整理后的记录、请求及采集时间、额度信息。
- `odds.csv`：可用 Excel 打开的表格，每个平台、玩法、方向分别一行。包含比赛、开赛时间、来源、让分或总分线、赔率及市场更新时间。

`point` 才是盘口数值；`price_decimal` 是赔率。例如 `point=-5.5` 表示该球队让 5.5 分；`totals` 下 `Over`、`Under` 分别表示大分、小分。让分正负号始终与具体球队绑定，不按数组先后猜测主客队。总分两边报价独立保存，不擅自假定相同。

时间保存为 UTC，也就是统一的国际时间；北京时间为 UTC 加 8 小时。脚本按开赛时间请求并再次过滤，已经到开赛时间的比赛不放进整理后的赛前记录；原始响应保留，方便核对。开赛时间过滤不能保证来源没有改期或状态延迟，正式产品仍需补赛程状态核对。

`market_last_update` 缺失时留空，不用平台更新时间冒充市场更新时间。当前未设置报价新鲜度阈值，不保证每条报价都是刚更新；使用时应查看更新时间。

## 限制与故障

此接口只返回已有报价的比赛，不是完整赛程。返回空列表不等于当天没有比赛。不同平台可能给出不同盘口，本脚本全部分开保留，尚未选定唯一参考平台，也不生成 AI 分析。

超时、鉴权或限流失败时停止，不输出带 Key 的请求地址或异常详情，不自动重试。重新手动运行可能再次消耗额度。即使本地未收到完整响应，服务端也可能已经处理并扣额度。

官网 2026-11-11 显示 Starter 免费方案每月 500 credits；后续以账号实际套餐为准。这个额度适合少量试接，不应直接开启高频轮询。
